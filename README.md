# Dilute-1

Dilute-1 is a small, train-from-scratch causal language model trained on responses generated by a DeepSeek teacher. The repository contains no second/student checkpoint: the only model created and optimized by the training command is Dilute-1. The teacher is used only during dataset generation and is never updated.

DeepSeek v4 is not bundled here. Pass the exact Hugging Face model ID or local model directory you have access to with `--teacher-model`; model access, licensing, and hardware requirements remain the operator's responsibility.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

PyTorch will use CUDA automatically when available. Install the CUDA-compatible PyTorch build appropriate for your GPU before installing this package if the default wheel is not suitable.

## Quick Start

After setup, run the complete default pipeline:

```bash
dilute1-pipeline
```

This automatically selects a built-in teacher, downloads WikiText, creates synthetic responses, trains a tokenizer, and trains Dilute-1. On machines with at least 5 GB free it uses `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`; on smaller machines it uses `HuggingFaceTB/SmolLM2-135M-Instruct` so the default run can complete. It uses 100 examples by default so the first run is practical. Add `--records 10000` for a larger dataset, or `--force` to regenerate existing files.

The larger built-in teacher is a public DeepSeek distillation checkpoint rather than an unavailable/private “DeepSeek v4” identifier. You can replace it without changing the pipeline code:

```bash
dilute1-pipeline --teacher-model YOUR_DEEPSEEK_MODEL --records 1000
```

## Manual Workflow

The following commands expose each stage separately.

### 1. Prepare WikiText prompts

Download WikiText through the Hugging Face Datasets library and turn passages into prompts for synthetic DeepSeek responses:

```bash
dilute1-wikitext \
	--output data/wikitext-prompts.jsonl \
	--config wikitext-103-raw-v1 \
	--split train \
	--max-records 10000
```

For a quick smoke test, use `--max-records 20`. The command keeps only non-empty passages and writes JSONL prompts; it does not call DeepSeek yet.

You can also create your own JSONL prompts. An example is in `data/prompts.example.jsonl`.

### 2. Train your tokenizer

Train a tokenizer from WikiText plus the synthetic responses. The two inputs are intentionally combined so Dilute-1 can represent both source language and teacher output:

```bash
dilute1-tokenizer \
	--input data/wikitext-prompts.jsonl data/teacher.jsonl \
	--output-dir outputs/tokenizer \
	--vocab-size 32000
```

You can also train from ordinary text files with `--format text`. The saved directory contains `tokenizer.json`, `tokenizer_config.json`, and the vocabulary files expected by Transformers.

### 3. Generate teacher data

Use the DeepSeek tokenizer and model to create the training set:

```bash
dilute1-generate \
	--teacher-model deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B \
	--prompts data/wikitext-prompts.jsonl \
	--output data/teacher.jsonl \
	--device auto
```

The generator runs inference only. It does not create or train a student model.

If the console commands are not found, use the module form from the repository root after activating `.venv`:

```bash
python -m dilute1.prepare_wikitext --output data/wikitext-prompts.jsonl --max-records 20
python -m dilute1.generate --teacher-model YOUR_DEEPSEEK_V4_MODEL_ID_OR_PATH --prompts data/wikitext-prompts.jsonl --output data/teacher.jsonl
python -m dilute1.tokenizer --input data/wikitext-prompts.jsonl data/teacher.jsonl --output-dir outputs/tokenizer
```

### 4. Train Dilute-1

This creates a fresh GPT-2-compatible Dilute-1 configuration and trains it on the teacher-generated text. The defaults are intentionally modest; increase the size only when the GPU and dataset support it.

```bash
dilute1-train \
	--data data/teacher.jsonl \
	--tokenizer outputs/tokenizer \
	--output-dir outputs/dilute-1 \
	--device auto \
	--precision auto
```

Useful controls:

- `--device cuda` requires CUDA and makes a missing GPU fail immediately.
- `--precision bf16` or `--precision fp16` selects mixed precision explicitly.
- `--resume` resumes the most recent Trainer checkpoint in `--output-dir`.
- `--layers`, `--hidden-size`, and `--heads` control Dilute-1's size.
- `--gradient-accumulation` increases the effective batch size without requiring more GPU memory.

For a cheap CPU smoke test, use a tiny tokenizer and dataset plus `--layers 2 --hidden-size 128 --heads 4 --max-length 256 --device cpu --precision no`.

## Design notes

- Teacher generation and Dilute-1 training are separate commands, so expensive teacher inference can be run once and reused.
- Training uses `safetensors` through Transformers checkpoints, gradient checkpointing, automatic mixed precision, and resumable saves.
- The current target is a trainable research baseline, not a claim of parity with DeepSeek. Model quality depends on teacher access, prompt coverage, filtering, and compute.

## Run a trained checkpoint

After training completes, run a prompt through Dilute-1:

```bash
dilute1-chat \
	--checkpoint outputs/dilute-1 \
	--prompt "Explain how neural networks learn."
```

Omit `--prompt` for interactive mode and type `/exit` to stop:

```bash
dilute1-chat --checkpoint outputs/dilute-1 --device auto
```
